# Школьная веб-мастерская

Учебный конструктор сайта о себе для 11 класса: HTML-блоки, CSS-классы, Flexbox, готовые картинки и сохранение в браузере. Практика рассчитана на 35 минут.

Исходники и подробная инструкция находятся в [web-lab](web-lab/README.md).

## Запуск

```sh
cd web-lab
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте http://127.0.0.1:4173/. Мастерская состоит из статических файлов и не требует установки пакетов.
