# Школьная веб-мастерская

Вводное занятие для 11 класса на 35 минут: небольшая страница о себе, HTML, семантика, явная вложенность блоков, CSS-классы и Flexbox. Картинку можно взять из библиотеки, загрузить с компьютера или отправить с телефона через QR в общей сети.

## Запуск

```sh
cd web-lab
python3 -B server.py
```

Откройте http://127.0.0.1:4173/. Сервер напечатает сетевой адрес для класса и телефонов. Установка пакетов не требуется.
