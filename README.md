# Страница «О себе»

Учебный редактор с тремя задачами: HTML и CSS; семантика и классы; Flexbox и карточки интересов. Перед задачей открывается теория, внизу отображаются процент выполнения и следующий шаг. Картинки доступны в библиотеке и с телефона по QR.

## Запуск

```sh
cd web-lab
python3 -B server.py
```

Откройте http://127.0.0.1:4173/. Сервер напечатает сетевой адрес для класса и телефонов. Python 3.9+, установка пакетов не требуется.
