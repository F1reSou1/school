# Страница «О себе»: три практические задачи

Каждая задача начинается с модального окна: короткая теория, пример структуры и список действий. «Начать задачу» открывает редактор. Теорию можно перечитать кнопкой «Теория» внизу.

Внизу постоянно видны задание, процент выполнения, выполненные действия и ближайший незавершённый шаг. «К шагу» выбирает нужный блок. Весь список действий раскрывается отдельно. На 100% появляется поздравление и кнопка перехода. Следующая задача открывается через свою теорию; редактор сам не переключает ученика.

## 1. HTML, CSS, блоки и классы

**Теория:** HTML задаёт содержимое и вложенность; CSS — Cascading Style Sheets, «каскадные таблицы стилей», отвечает за оформление. Теги ограничивают элементы, контейнер включает детей. Класс связывает `class="page"` с правилом `.page { … }`. Один класс можно назначить нескольким элементам.

Каскад выбирает значение, когда одному элементу подходит несколько правил: учитываются важность, точность селектора и порядок записи. При равных остальных условиях действует последнее правило. Наследование передаёт от родителя некоторые свойства, например цвет текста и шрифт; фон, ширина и отступы по умолчанию не наследуются.

В примере `main.page` задаёт серый цвет и Arial. Вложенный `h1` наследует оба свойства, а `p.page__intro` получает свой синий цвет из `.page__intro`, продолжая наследовать шрифт. Явно заданное самому ребёнку значение имеет приоритет над унаследованным значением этого свойства. Это не означает, что класс ребёнка побеждает любое другое правило: конфликты правил, применённых непосредственно к ребёнку, решает каскад.

**Задача:**

1. Выбрать `main.page` и класс `page`.
2. Изменить фон у `.page`.
3. Вписать имя в `h1`.
4. Изменить абзац знакомства в `header.hero`.

Каждое действие даёт 25%. Фон другого блока не засчитывается как фон страницы. Можно использовать вымышленное имя.

## 2. Семантика, БЭМ и вступление

**Теория:** роль `main`, `header`, `section`, `article`, `div`, `figure`, `img`, `h1`, `h2`, `p`, `footer`. Скринридерам семантика помогает находить разделы и заголовки; поисковым роботам — понимать структуру. Описание `alt` помогает людям, которые не видят изображение; у декоративного изображения оно пустое. В заданиях это поле необязательно.

БЭМ: блок, элемент, модификатор. Весь урок использует запись `блок__элемент`: два подчёркивания отделяют имя элемента от блока. Сам блок — `hero`, его элементы — `hero__item` и `hero__img`, пример модификатора — `hero__item--wide`. У блока `interesting` элементы называются `interesting__card`, `interesting__title` и `interesting__description`. Имена самостоятельных блоков (`page`, `hero`, `interesting`) не требуют `__`. В HTML классы пишем без точки, в CSS — с точкой.

**Задача:**

1. В `header.hero` создать `div.hero__item`.
2. Переместить существующие `h1` и `p` внутрь этого контейнера.
3. Рядом, также внутри `hero`, добавить `img.hero__img`.
4. Заменить изображение своим фото с телефона по QR.
5. У класса `hero__item` ограничить ширину текстового блока до 360 px или меньше: «Оформление → Макс. ширина блока». Подойдёт и обычная ширина `width` в этих пределах.
6. Выбрать само `img` и уменьшить его ширину до 240 px или меньше. Описание `alt` можно оставить пустым.

Вступление должно иметь такую вложенность:

```text
header.hero {
  div.hero__item { h1, p }
  img.hero__img
}
```

Для `img` обёртка не нужна. Варианты `figure.hero__img { img }` и `div.hero__img { img }` также засчитываются. `figure` обозначает самостоятельную иллюстрацию и может содержать подпись `figcaption`.

Перенос доступен и перетаскиванием, и через поле «Родитель». Фото добавляется в выбранный контейнер, повторный выбор заменяет его прямую дочернюю картинку. Готовые фото доступны, но шаг «через QR» выполняется только после фактического получения фото от телефона. Проверяются отдельно обе ширины: текстового блока и картинки. Изменение только скругления не заменяет уменьшение фото. `width` задаёт ширину, `max-width` ограничивает её сверху: блок может быть уже, но не шире. Пустое описание `alt` не снижает прогресс.

## 3. Flexbox и четыре карточки

**Теория:** Flexbox включается у родителя и располагает прямых детей. `row` — строка, `column` — колонка, `gap` — расстояние, `justify-content` и `align-items` управляют разными осями. При смене направления оси меняются местами. Общие классы обеспечивают единое оформление.

**Задача:**

1. У `header.hero` включить Flexbox в строку.
2. Проверить, что текст и фото с размерами из прошлого задания помещаются в строку, настроить расстояние между ними.
3. В разделе «Мои интересы» создать `article.interesting`.
4. Вложить в него четыре `div` с общим классом, например `interesting__card`.
5. В каждой карточке создать два `p`: `interesting__title` и `interesting__description`, заполнить их своим текстом и вставить картинку. Описание `alt` необязательно.
6. Настроить общий класс карточек и оба текстовых класса.

Каждая карточка проверяется отдельно: её наличие, название, описание и фото. Нужны ровно четыре карточки, реальные CSS-правила общих классов и одинаковые настройки у соответствующих элементов. Нельзя получить 100% одной карточкой или только перечислением имён классов без оформления.

Удобный путь: собрать первую карточку, настроить классы, дублировать её три раза кнопкой ⧉ и заменить содержание в копиях.

После 100% у всех трёх задач ученик сохраняет страницу. Если предыдущая задача стала неполной после редактирования, редактор предложит вернуться к ней.

## Запуск и сохранение

```sh
cd web-lab
python3 -B server.py
```

Компьютер и телефон для QR должны находиться в одной сети. Если сеть изолирует устройства, это нужно решить до урока: библиотека картинок не заменяет проверку передачи по QR.

Прогресс, просмотренные теоретические вводные и информация об отправленных картинках сохраняются вместе с проектом. При обновлении сценария создаётся новая заготовка, прежние работы остаются в «Проекты».

Источники теории: [семантика HTML · MDN](https://developer.mozilla.org/en-US/docs/Glossary/Semantics), [БЭМ](https://getbem.com/naming/), [Flexbox · MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Flexible_box_layout/Basic_concepts).
