# Веб-мастерская — страница о себе

Вводное занятие на 35 минут. Ученик собирает небольшую страницу: имя, знакомство, раздел об увлечении, картинка и подпись. Задания знакомят с HTML, смысловыми тегами, вложенностью, блочной моделью, CSS-классами и Flexbox. Подробный сценарий для учителя — [LESSON.md](LESSON.md).

## Запуск

```sh
cd web-lab
python3 -B server.py
```

Установка пакетов не нужна; требуется Python 3.9 или новее. На компьютере откройте http://127.0.0.1:4173/. Сервер также печатает адрес для телефонов и остальных компьютеров класса.

Для QR телефон и компьютер должны находиться в одной сети. Сервер слушает порт 4173 на сетевых интерфейсах. Если школьная сеть изолирует устройства или брандмауэр блокирует соединение, остаются загрузка с компьютера и библиотека. На компьютере с несколькими сетями адрес можно указать явно:

```sh
python3 -B server.py --public-url http://192.168.1.10:4173
```

Для запуска только на одном компьютере: `python3 -B server.py --bind 127.0.0.1`. Обычный статический хостинг или `python3 -m http.server 4173 --bind 127.0.0.1` поддерживает редактор и загрузку с компьютера, но без передачи фото по QR.

## Шесть шагов

1. **О себе, 5 мин.** Изменить h1 и текст знакомства внутри header.
2. **Блоки, 7 мин.** Заменить нейтральный div.about на section, вложить h2 и свой абзац p.
3. **Фото, 6 мин.** Вставить img внутрь figure, заполнить alt и изменить width.
4. **Flexbox, 8 мин.** Включить Flexbox у родителя картинки, попробовать justify-content и align-items: центр, левый и нижний край; сравнить ряд и колонку.
5. **CSS-класс, 6 мин.** Создать my-style с фоном и padding, назначить разделу и увидеть связь class="my-style" / .my-style { … }.
6. **Результат, 3 мин.** Проверить узкий экран, назвать проект и сохранить.

Проверка читает настоящий HTML и CSS: учитывает вложенность, смену смыслового тега, свой текст, ширину картинки, выравнивание у её непосредственного родителя и применение класса. Редактирование кода вручную также поддерживается.

## Вложенность

- Контейнеры показаны парными скобками, цветными вертикальными линиями и отступами. Дети находятся между скобками своего родителя.
- Пустой или свёрнутый контейнер выглядит как `{ }`. При наведении перетаскиваемого блока скобки раскрываются и показывают место вставки.
- Кнопки рядом с тегами сворачивают и раскрывают группы. Скобки — подсказка редактора; настоящий HTML использует открывающий и закрывающий теги.
- Для работы без перетаскивания можно выбрать контейнер и нажать блок в библиотеке или изменить «Вложить в контейнер» у существующего элемента.
- Навигационная цепочка над настройками показывает родителей выбранного блока. Настройки смыслового тега объясняют main, header, section, figure, footer и div.
- В оформлении есть схема блочной модели: содержимое, padding, border, margin.

## Фото

В библиотеке находятся шесть встроенных изображений из `assets/`; источники — `assets/credits.json`. Также доступны JPG, PNG, WebP и GIF с компьютера или телефона. Перед вставкой собственное изображение преобразуется в JPG, уменьшается до 960 px по длинной стороне и до 220 000 символов data URL. Анимация GIF превращается в статичный кадр. HEIC нужно предварительно сохранить в JPG.

QR создаётся локально библиотекой Project Nayuki, включённой в `vendor/` с MIT-лицензией. Внешние сервисы и интернет для передачи фото не нужны. QR открывает страницу отправки на телефоне; изображение автоматически приходит в выбранный блок проекта. Окно QR на компьютере нужно оставить открытым.

Каждый QR принимает одну картинку, действует 10 минут и использует отдельные ключи отправки и чтения. Фото временно хранится в памяти сервера. При закрытии окна или успешном приёме сеанс удаляется; перезапуск сервера удаляет все сеансы. Затем копия картинки хранится в HTML проекта в браузере и переносится вместе с кодом WL1.

## Сохранение

Автосохранение использует localStorage этого браузера и адреса. «Сохранить» создаёт контрольную версию (до шести на проект). «Мои проекты» позволяет переключаться между работами. При первом открытии обновлённого урока создаётся новая заготовка, прежние проекты остаются в коллекции.

«Результат → Код проекта» выдаёт переносимый код WL1 с HTML, CSS, необязательным JavaScript и загруженными картинками. Его можно открыть на другом компьютере через «Мои проекты → Открыть по коду». Очистка данных браузера удаляет локальную копию. Большое число фото и контрольных версий может заполнить память; в этом случае сохраните код отдельно. Импорт ограничен 700 000 байт распакованного проекта.

## Проверка

```sh
node --check app.js
node --check photo.js
node --check upload.js
python3 -B -m unittest discover -s tests -v
```

HTTP-тесты проверяют передачу фото, изоляцию сеансов, QR, истечение и отзыв ссылок, повторы отправки и обработку ошибочных запросов.

Файлы: `index.html`, `app.css`, `app.js` — редактор; `photo.js` — подготовка фото; `upload.*` — экран телефона; `server.py` — локальный сервер и передача фото; `assets/` — встроенные картинки; `vendor/` — генератор QR.
