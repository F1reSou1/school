# Веб-мастерская

Статическая учебная мастерская для 11 класса на 35 минут: сайт о себе, HTML-блоки, CSS-классы, Flexbox, встроенные картинки и сохранение проектов в браузере. Серверная логика и API удалены.

## Локальный запуск

Из папки `web-lab`:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4173. Это только раздача статических файлов; устанавливать пакеты не нужно. Приложение можно разместить на обычном статическом хостинге.

## Сборка и оформление

- Drag-and-drop новых блоков, перестановка и вложение в контейнеры; кнопки и стрелки доступны как альтернатива перетаскиванию.
- Файлы `index.html`, `style.css` и необязательный `script.js`; ручное редактирование кода.
- Отдельная панель содержимого, CSS-классов и оформления выбранного блока.
- Цвета, размер текста, отступы, скругления, выравнивание.
- Flexbox у контейнера: ряд/колонка, gap, justify-content, align-items, flex-wrap. Изменения записываются в настоящий CSS-класс.
- Три палитры и предпросмотр на ширине 720 и 320 px; большой просмотр готового сайта.
- Пять заданий: собственный текст; четыре карточки «Увлечения», «Планы», «Характер», «Способности»; Flexbox; общий CSS-класс; картинка и сохранение. В новой заготовке готова только карточка «Увлечения», остальные ученики создают сами.
- Проверка карточек учитывает заголовки и заполненный текст внутри #interests .cards; Flexbox проверяется у этого контейнера (ряд, gap 16–24 px, wrap, четыре карточки).

## Картинки

Шесть фотографий включены в `assets/`: горы, океан, космос, планета, музыка, спорт. Ученики выбирают их в библиотеке. Загрузки файлов с компьютера в интерфейсе нет. Источники и лицензия указаны в `assets/credits.json`.

Фотографии загружаются из самой мастерской. Код проекта сохраняет выбор изображения из этой библиотеки; скачивания файлов в интерфейсе нет.

## Сохранение и перенос

- Автосохранение хранит текущий проект и активный выбор в localStorage этого браузера.
- «Мои проекты» позволяет переключать работы и создавать новые без потери предыдущих.
- «Сохранить» создаёт контрольную версию; хранится до шести версий каждого проекта.
- «Результат → Код проекта» выдаёт текст WL1, включающий код и настройки. Скопированный текст можно сохранить отдельно и вставить в «Мои проекты → Открыть по коду» на другом компьютере. Импорт создаёт новый проект.
- Сохранение в браузере зависит от компьютера, профиля и адреса мастерской. Очистка данных браузера удаляет эту копию; отдельно сохранённый код проекта позволяет восстановить работу.
- Черновики прошлой версии мигрируют при первом открытии. Серверные данные предыдущего прототипа не используются и сохранены отдельно в соседней папке `web-lab-legacy-data`.

## Файлы

`index.html` — интерфейс; `app.css` — оформление; `app.js` — редактор, учебные задания и сохранение; `assets/` — готовые фотографии.
