      CSS — как выглядит
      Фон, шрифт, отступы, скругления. Класс позволяет применить один стиль сразу к нескольким элементам.
      ↔
      Flexbox — как расположено
      Включается у родительского контейнера. Управляет расположением его прямых дочерних блоков.
      Блочная модель
      Элемент занимает прямоугольную область: содержимое, внутренний отступ padding, граница border, внешний отступ margin. Увеличь отступ у своего класса: фон станет просторнее, а текст останется тем же.
      Вложенность и смысл
      В редакторе { } обозначают границы контейнера: все строки между скобками — его дети. Это подсказка редактора; в HTML вложенность записана тегами <section> … </section>. main — главное содержимое, header — вступление, section — раздел, footer — завершение. Смысловой тег выбирается в настройках блока.
      Ряд и колонка
      flex-direction: row выстраивает блоки по горизонтали, column — по вертикали. gap задаёт расстояние. justify-content выравнивает по главной оси, align-items — по поперечной. Перенос wrap помогает блокам поместиться на узком экране.

      Картинки и сохранение
      Картинки доступны в библиотеке и по QR с телефона (в одной сети). Автосохранение хранит проект в этом браузере; кнопка «Сохранить» делает контрольную версию. Через «Результат → Код проекта» можно скопировать работу и открыть её позже без загрузки файлов.
