# Новые изображения библиотеки

Созданы встроенным инструментом `image_gen`, без CLI и API-ключа. Три исходных PNG сохранены инструментом; в проект добавлены JPEG с длинной стороной 1200 px для быстрой загрузки. Это отдельные изображения, а не части коллажа. Имена, описания и категории заданы в IMAGES в app.js; источники отмечены в assets/credits.json.

## Рыжий кот

Файл: [assets/cat-window.jpg](assets/cat-window.jpg), категория «Природа».

Промпт:

> Use case: photorealistic-natural. Asset type: school website image library for students making an about-me page. Primary request: a warm natural editorial photograph of an expressive ginger cat sitting on a sunny windowsill with a few leafy plants, soft morning light, attractive candid detail. Landscape 4:3, visually clear at small thumbnail size, sharp fur and eyes, peaceful mood. No text, no brands, no watermark. Save the generated image file for use in the local project.
